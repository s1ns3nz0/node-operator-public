description: Create and maintain a task contract, graph, plan, and evidence bundle for non-trivial node-operator work.
---

Before non-trivial implementation, create `plans/<task-id>/` with
`task-contract.json`, `plan.md`, `graph.json`, `graph.mmd`, and `evidence.json`.
Record named model tier, file boundary, worktree/branch, acceptance checks,
and escalation trigger. Keep JSON, Mermaid, and plan status synchronized.
